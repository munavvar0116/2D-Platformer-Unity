# 🎮 2D Platformer Game (Unity)

A simple 2D platformer built using Unity and C#.

## Features
- Player movement (left/right)
- Jump mechanics
- Platform-based level design
- Death/reset system
- Custom sprites (Kenney assets)

## Tech
- Unity
- C#
